# Step 12 examples

Open any `.openscroll` file in the portable project workspace or import it into your library. Each contains original editable OpenScroll content. `workshop.openscroll` uses the Plum theme; `guided-workshop-plum.pdf` demonstrates its static PDF version.

Generate fresh examples with `npx tsx tools/step12-examples.ts`. See [themes and reuse](../../docs/THEMES-AND-REUSE.md) for authoring instructions.
