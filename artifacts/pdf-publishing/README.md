# PDF publishing samples

- `learning-that-travels.pdf`: A4 learner copy, 12 pages, without assessment keys.
- `learning-that-travels-with-answers.pdf`: US Letter instructor copy, 15 pages, with an answer-key/feedback appendix.
- `learning-that-travels.openscroll`: editable source for both samples.

Generated through the production PDF endpoint. The source includes representative images, media transcripts/captions, expanded interactive content, all five assessment formats, narration text and long-form pagination. Media and companion files are represented as static text rather than embedded playable/downloadable resources.

Tagged structure, headings, language, image alternative text, bookmarks, text order and page bounds were checked. Manual screen-reader and PDF/UA certification are not claimed. See `docs/PDF-PUBLISHING.md` and `docs/STEP-11-VALIDATION.md` in the source repository.
