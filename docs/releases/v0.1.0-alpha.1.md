# OpenScroll v0.1.0-alpha.1

First development prerelease of the OpenStage family's open-source course authoring tool.

## Included

- Private author accounts and course library, course/lesson organization, autosave, revision conflict protection and recovery drafts.
- Editable portable `.openscroll` projects, block authoring with undo/redo, media/interactions and assessments.
- Shared learner preview, standalone HTML, SCORM 1.2, SCORM 2004 4th Edition and static PDF publishing.
- Theme settings, original templates, reusable groups/assets and course snapshots with safe restoration.
- Official OpenScroll icon, independent production containers, operator controls, asset quotas, backup/restore and upgrade tooling.

## Validation

81 unit tests, 37 PostgreSQL integration tests and 42 Chromium browser tests pass (160 total). The production-image drill passes fresh installation, backup-first upgrade, restart persistence, backup integrity rejection and restoration into an isolated empty database, historical session revocation, HTTPS with a trusted local test issuer and PDF export in the hardened runtime.

## Deployment and limits

Start with `DEPLOYMENT-HANDOFF.md` and `docs/SELF-HOSTING.md`. Database migration 4 is current; portable schema 3 remains current. Credentials are not included. The source/deployment ZIP is also available under `artifacts/releases/` with a checksum sidecar.

This is a prerelease for review and pilot preparation. Live Hostinger deployment, public DNS/certificate issuance, real SMTP delivery and encrypted off-host backup acceptance remain pending. Preserve existing Pressbooks and other VPS services. Manual assistive-technology, wider-browser and PDF/UA validation are not complete; no certification is claimed. Both SCORM editions passed user acceptance in Brightspace, while detailed gradebook/resume/retake evidence remains unrecorded.
