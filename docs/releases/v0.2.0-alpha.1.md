# OpenScroll v0.2.0-alpha.1 (draft)

Draft release notes for the schema 4 release. Not tagged and not released: see
[RELEASE-0.2-CHECKLIST.md](../RELEASE-0.2-CHECKLIST.md) for what must happen first.

## Included

- **OpenScroll Studio**, a redesigned workspace at `/studio/` behind the `OPENSCROLL_STUDIO` instance setting (off
  by default in production). Library with Resume, course page with the outline edited in place, details panel and
  theme studio, and a lesson editor that shows the lesson as learners see it, with an inspector, block picker,
  undo and redo, Checks, device preview and an export dialog. The classic workspace stays available.
- **Portable schema 4.** Lesson banners and objectives, per-choice feedback, canonical formatted text, and every
  new block's shape. Version 1, 2 and 3 projects and stored courses open as version 4 without losing content;
  stored rows keep their version until an author saves.
- **Rise 360 import** from a Rise website export, with an import report.
- **New blocks.** Learning objectives, tables, reflections, activities, checklists, self-assessments, columns,
  true or false, short answer with a model answer, numeric, hotspot, survey, interactive video with chapters and
  checkpoints, audio description, embedded YouTube or Vimeo video (off unless `OPENSCROLL_EXTERNAL_VIDEO=on`),
  software practice with OpenStage Capture import, glossary, action plan, results with a certificate, questions
  drawn from a bank, and branching scenarios with characters.
- **Learner responses and My workbook.** Written work is kept with the learner's progress and can be downloaded.
- **Per-question LMS reporting** through `cmi.interactions` in both SCORM editions, with resume format 4.
- **Course resources.** Glossary with term links, question banks with `.openassess` import, characters and a
  certificate.

## Compatibility

Projects saved by this version cannot be opened by v0.1.x servers, which reject them with a clear message and
leave the file unchanged. SCORM packages exported by v0.1.x keep working as they are. A course re-exported by this
version is a changed publication: as before, start a new LMS attempt after replacing a package, because resume
data is bound to the publication it came from.

## Validation

To be completed before release: the unit, PostgreSQL integration and Chromium browser suites in CI; Brightspace
checks for both SCORM editions, including per-question reporting; the migration rehearsal on a restored copy of
production; and accessibility and usability sessions. See the checklist.

## Deployment

Follow the backup-first plan in `DEPLOYMENT-HANDOFF.md`. Schema 4 needs no database migration: it changes the
course format, which the server upgrades on read. Run `npm run db:rehearse` against a restored copy of production
before the cutover. Turn on `OPENSCROLL_STUDIO` once the studio is accepted; turn on `OPENSCROLL_EXTERNAL_VIDEO`
only if embedded video is approved for your installation.
