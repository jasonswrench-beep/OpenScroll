# OpenScroll v0.2.0-alpha.2

A small follow-up to [v0.2.0-alpha.1](v0.2.0-alpha.1.md): the studio becomes the place authors start.

## Changed

- **Signing in opens the studio** where the instance has it turned on (`OPENSCROLL_STUDIO=on`). The account page's
  main button reads **Open the studio**, with a **Classic workspace** link beside it. The classic workspace keeps
  every tool and its own link to the studio. Where the studio is off, signing in and the account page lead to the
  classic workspace as before.

## Validation

- GitHub checks on the release commit: unit tests, PostgreSQL integration tests, the Chromium browser suite (which
  now expects the studio after sign-in and checks both account-page links), the final-image tests and the
  production rehearsal.
- The account page passes axe (WCAG 2.2 A and AA) with both links shown.

## Deployment

Images only: no database or settings change. Build the app and renderer images from the tagged commit and replace
the running pair; the previous pair stays available for rollback.
