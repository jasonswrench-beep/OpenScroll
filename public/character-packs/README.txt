Character and background packs for scenarios

These two packs come from OpenStage Author: "OpenStage people, set 1" (fifteen people, each in many poses) and
"OpenStage offices and workplaces, set 1" (fifty-eight empty places to set a scene in). Each folder holds the pictures
and a pack.json that names them and describes each one for screen reader users.

In OpenScroll Studio, open Course resources, then Characters, and choose "Choose from the library" to add a person
with the poses you want. In a scenario, choose a scene and "Choose from the library" to set its background. The
pictures you choose are copied into the course, so a published course needs nothing from this folder.

Made by Jason S. Wrench with an AI picture service from written descriptions (AI-generated). Released under the
Apache License 2.0. The NOTICE file that every published course carries says so.

Keep these folders as they are: OpenScroll reads pack.json to list the pictures.
